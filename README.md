# PRODIGY_DS_01

## 📌 Objective
Create a bar chart and histogram to visualize the population distribution using the World Bank Population Dataset.

## 🛠️ Tools Used
- Python
- Pandas
- Matplotlib

## 📂 Dataset
World Bank Population Dataset (2025)

## 📊 Visualizations
- Top 10 Most Populated Countries (Bar Chart)
- Population Distribution (Histogram)

## 📈 Insights
- India and China have the highest populations.
- Most countries have relatively smaller populations.
- Population distribution is highly uneven.
- The dataset contains one missing value for the latest year.
